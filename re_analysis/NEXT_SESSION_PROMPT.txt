**IMPORTANT DISCOVERY - The Constant Mismatch:**
Path B2 reported that address 0x00464688 contains the 4.0 WES:RES ratio constant.
However, binary analysis reveals:

  - Address 0x00464688 actually contains: 100.0 (not 4.0!)
  - Actual 4.0 constants are located at:
    * 0x00464ad8 (in .rdata section, file offset 0x00063cd8)
    * 0x00478798 (in .data section, file offset 0x00077998)

**The Three FMUL Instructions (All use 100.0 at 0x00464688):**
1. 0x0040f871 - FMUL double ptr [0x00464688]  Loads: [EAX + 0x208]
   Purpose: Multiplies unknown ship field by 100.0 for display

2. 0x0040f997 - FMUL double ptr [0x00464688]  Loads: [ECX + 0x1c8]
   Purpose: Multiplies reactor power level by 100.0 for display

3. 0x0040fc87 - FMUL double ptr [0x00464688]  Loads: [ECX + 0x390]
   Purpose: Multiplies shield capacity by 100.0 for display

All three are inside FUN_0040f4b0, the main ship status display function.

**Key Ship Structure Offsets Discovered:**
- 0x208: Unknown field (first FMUL operand)
- 0x1c0: Reactor output/power (used in calculations)
- 0x1c8: Reactor power level (second FMUL operand)
- 0x1d0: Shield type
- 0x38: Divisor in power calculations
- 0x390: Shield capacity (third FMUL operand)
- 0x58, 0x90: Weapon counts (different types)
- 0x200, 0x110, 0x158: Different reactor types
- 0x2d0: Unknown (possibly armor/defense)

**Related game text:**
"Reinforced shields require 4x power" (0x004662f0) - confirms 4:1 WES:RES ratio
is intentional game balance design. (Note: This text references 4x, but the FMUL
instructions use 100.0. Need to understand relationship.)
