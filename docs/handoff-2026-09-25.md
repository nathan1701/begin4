    (Ghidra label `s_Manual_helm_00469300`), referenced via a pointer at `0048f044`

    this is likely one entry in a small **lookup table of NAVCOM-state strings** (Manual Helm,
    Auto Helm, Pursuing, Eluding, etc.), not the command parser itself.
